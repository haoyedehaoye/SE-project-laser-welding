version 0.1
The project is currently under active development, with the current focus on building a monolithic application for testing purposes.

This monolith has implemented the following capabilities: simulated STM32 device data transmission and upload to a visualization table for display. An initial version of the visualization table interface is now in place.

How to Run: Navigate to the test directory, launch the simulator file first, then run the main file. After that, open your browser and visit localhost:18080 to view the real-time data.

The contents in other folders pertain to the production version, which is still under construction.
