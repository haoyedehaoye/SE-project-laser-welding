## 三、结果复盘（诚实结论）

1. **真实数据立住了结论**：V1（金相裂纹 + 几何实测）上裂纹 AUC≈0.98；几何回归可解释量级（熔宽/熔深 R² .86–.91，间隙 .59 最弱）。
2. **唯一硬约束 = 只有 5 道焊缝**：每折只测 1 道焊缝，AUC 偏乐观、方差大 → 一切数字按“趋势参考”对待。
3. **模型选择不是当前瓶颈（任务 2 结论）**：裂纹任务 5 模型基本持平 → 沿用 XGBoost；窗口任务 RandomForest 更优但结论基于合成数据 → 列为候选，待真实时序数据复评。
4. **合成口径与真实口径严格分开**：`xgb_anomaly`（合成）只用于实时流程演示。
5. **已知待修口径**：`detect_demo.py`（suspicious 折叠、XGB 窗口分取值）——列入 P0-2。

## 四、下一阶段实验计划（每项含做法与验收）

### P0-1 扩大真实标注焊缝数据 ★最关键
- 目标：累计 **≥30–50 道带裂纹标签焊缝**（真机或补充公开数据）。
- 做法：编写采集/标注运行手册；每道焊缝多横截面采样（沿用 V1 格式与列名）。
- 验收：按焊缝分组 CV 的 **AUC 折间 std < 0.02**，且焊缝级准确率的置信区间可计算。

### P0-2 修 `detect_demo.py` 对比口径并重跑窗口域多方法
- 做法：suspicious 单独统计；所有方法（含 XGB）统一 32 帧窗口特征打分；无监督拟合用独立正常段。
- 验收：同一窗口集合上输出各方法指标，口径说明可写入报告。

### P1-1 真机硬件接入与录制（要求 5 的执行）
- 做法：按 `processing/config.yaml` 拓扑接 STM32（真机/串口服务器）→ 录制带标签焊接段；相机/热像到位后接图像模态。
- 验收：真机数据稳定进仪表盘；录制数据可回放并导出与 V1 同构样本。

### P1-2 扩大数据后重训多输出模型 + 阈值重标定
- 做法：复用 `train_multiout.py` / `compare_models.py`，数据替换为 P0-1 新数据。
- 验收：新焊缝分组 CV 上裂纹 PR-AUC 与几何 R² 收敛，阈值按业务漏检/误报成本重标。

### P2-1 真多模态融合
- 做法：传感器时间序列窗口统计 + 工艺参数 + 图像特征（相机到位后），late-fusion；QA 解释接预测。
- 验收：融合在新焊缝评估上 ≥ 单模态，能定位主导模态。

### P2-2 寿命/剩余寿命（RUL）
- 做法：需连续运行记录（时间序列 + 故障时刻），样本量满足 01 文档约束后按事件级建模。
- 验收：给出可评估的 RUL 模型与误差带。
