# 正式框架与工业相机接入

> 实施日期：2026-09-10  
> 状态：正式框架和 MVS 适配代码已完成；等待本机安装 MVS 后进行真实相机取帧验证。

## 1. 已实现内容

- 独立于 `test/` 的 `app` 正式 Python 包。
- TOML 配置和环境变量覆盖。
- 标准库日志轮转，不再依赖两套不同日志库。
- 服务按顺序启动、逆序停止，启动失败时自动回滚。
- 统一的设备事件和设备状态数据契约。
- 海康 MVS SDK 动态加载。
- GigE/USB 相机枚举。
- 按序列号、IP或第一台可用相机选择设备。
- 相机独占打开、最佳 GigE 包大小设置、连续取流。
- 黑白相机转 Mono8，彩色相机转 RGB8。
- 不依赖 OpenCV/Pillow 的 PNG 实时预览编码。
- 相机断线或SDK不可用时保留Web服务并自动重试。
- 浏览器实时画面、连接状态和设备枚举页面。
- 健康检查、相机状态、设备枚举和实时图像流接口。

本阶段没有实现录像和三天清理；它属于后续视频存储阶段。

## 3. HTTP接口

| 地址 | 作用 |
|---|---|
| `/` | 工业相机实时监控页面 |
| `/api/health` | 系统健康状态 |
| `/api/camera/status` | 相机连接、帧数、分辨率和错误信息 |
| `/api/camera/devices` | 通过MVS重新枚举设备 |
| `/api/camera/stream` | 浏览器实时PNG多帧流 |

页面明确不展示焊接状态、缺陷识别或视觉质量结果。

## 4. 相机规格依据

依据 `D:\SEproject\外加硬件\MV-CS050-10GMGC_20241101.pdf`：

- 型号：MV-CS050-10GM（黑白）或 MV-CS050-10GC（彩色）。
- 传感器：Sony IMX264，全局快门。
- 分辨率：2448 × 2048。
- 最大帧率：24.2 fps。
- 接口：Gigabit Ethernet，兼容 GigE Vision V2.0 和 GenICam。
- 供电：9～24 VDC 或 PoE。
- 操作系统：支持 Windows 10/11 32/64位。

## 6. 真实相机联调前置步骤

1. 从海康机器人官方渠道安装适合 Windows 64位的 MVS 客户端和SDK。
2. 打开 MVS 客户端，确认能够枚举 MV-CS050-10GM/GC。
3. 如果相机与电脑不在同一网段，在 MVS 中为相机配置持久IP，并给 Realtek 网卡配置同网段静态IP。
4. 用 MVS 客户端先完成一次连续取流，确认镜头、曝光和供电正常。
5. 找到 MVS 安装目录中的 `Development\Samples\Python\MvImport`。
6. 把该路径填写到 `config/app.toml` 的 `mvs_python_path`。
7. 首次成功枚举后，把相机序列号填入 `serial_number`，避免以后错误选择其他相机。

建议网络示例（必须以MVS实际显示的相机IP为准）：

```text
电脑 Realtek 网卡：192.168.1.100 / 255.255.255.0
工业相机：          192.168.1.150 / 255.255.255.0
```

不要在未确认相机当前地址前直接套用上述示例。
