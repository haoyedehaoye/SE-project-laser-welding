# 激光焊接预测性维护系统 — 运行指南

> 覆盖：运行整个项目、运行/训练/评估检测模型。所有命令在 `test\` 目录下执行。

## 一、运行整个项目（系统）

### 0. 环境准备（新电脑只需一次）

```powershell
cd D:\SEproject\AIFirst\LaserWelding
.\.venv\Scripts\python.exe -m pip install -r test\requirements.txt
```

- 依赖：fastapi、uvicorn、websockets、numpy、scipy、scikit-learn、xgboost、openai（版本已固定）。
- 模型文件必须存在：`models\` 下要有 `xgb_anomaly\model.json` 等；缺失时主程序自动回退为规则质检。

### 1. 方式一：VS Code 一键启动（推荐）

1. VS Code 打开项目文件夹 `D:\SEproject\AIFirst\LaserWelding`；
2. 菜单 **终端 → 运行任务…** → 选择 **`焊接监控: 一键启动整个系统`**；
3. 自动弹出两个终端：终端 1 模拟器（8234），终端 2 主程序（仪表盘）。

### 2. 方式二：手动终端

```powershell
cd D:\SEproject\AIFirst\LaserWelding\test
.\.venv\Scripts\python.exe simulator.py   # 终端 1，先启动
.\.venv\Scripts\python.exe main.py        # 终端 2，再启动
```

### 3. 查看与停止

- 仪表盘：http://localhost:18080（曲线、质检三档、告警）；
- 问答页（可选）：http://localhost:18080/qa（需 `config.py` 里 `QA_ENABLED=True` 并配好 Key）；
- 停止：对应终端按 `Ctrl+C`，主程序打印最终质检统计后退出。

### 4. 运行成功的判断标准

主程序终端依次出现：


## 二、运行检测模型

### 1. 一键运行（推荐）

VS Code：菜单 **终端 → 运行任务…** → 选择 **`焊接监控: 一键运行检测模型`**；

等价命令：

```powershell
cd D:\SEproject\AIFirst\LaserWelding\test
.\.venv\Scripts\python.exe model_demo.py
```

脚本加载 `models\xgb_anomaly\model.json`，先生成 40 帧正常数据（前 32 帧规则冷启动），再生成 40 帧"温度爬升 + 故障位"数据，最后打印判定结果和质检统计。

### 2. 训练模型

窗口版（温度/电压/状态，主程序使用）：

```powershell
.\.venv\Scripts\python.exe train_xgboost.py                    # 合成数据
.\.venv\Scripts\python.exe train_xgboost.py --csv 你的数据.csv  # 真实数据
```

CSV 列：`temperature, voltage, status, label`（0 正常/1 异常），可选 `run_id`（按 run 分组防泄漏）。模型存到 `models\xgb_anomaly\`。

> 注：`xgb_anomaly` 保留合成数据版，未用搭接接头 V1 重训（V1 只有工艺参数，无温度/电压时间序列）。

搭接接头 V1 变体版（`xgb_public` 系列）：

```powershell
.\.venv\Scripts\python.exe train_public_dataset.py                        # 训练全部 3 个变体
.\.venv\Scripts\python.exe train_public_dataset.py --variant group        # 按焊缝分组（防泄漏）
.\.venv\Scripts\python.exe train_public_dataset.py --variant sensor-only  # 4 个核心参数（消融）
```

数据：`Definitive screening steel-copper lap joints V1.xlsx`（360 行，310 no / 50 yes 裂纹；V2 无标签仅参考）。`xgb_public` → 6 参数随机切分；`xgb_public_group` → 6 参数按 `weld number` 分组切分；`xgb_public_sensor_only` → 功率/速度/气流量/板厚 4 参数。

### 3. 评估模型准确度

窗口版 `xgb_anomaly`：准确度在训练输出里，看 **`test evaluation (unseen runs)`** 段（`evaluate_model.py` 不支持窗口版）。当前合成数据：accuracy 86.43%、AUC 0.9299。

V1 模型版（`xgb_public` 系列 / 逐行分类）：

```powershell
.\.venv\Scripts\python.exe evaluate_model.py --model-dir models/xgb_public
.\.venv\Scripts\python.exe evaluate_model.py --model-dir models/xgb_public --cv 5
.\.venv\Scripts\python.exe evaluate_model.py --model-dir models/xgb_public_sensor_only
.\.venv\Scripts\python.exe evaluate_model.py --model-dir models/xgb_public --xlsx 新数据.xlsx --test-size 0
```

输出 accuracy、balanced accuracy、ROC-AUC、PR-AUC、Brier、F1、混淆矩阵、三档映射、按焊缝分组准确率；报告存模型目录下 `eval_report.json`。

## 三、多输出质量模型（真实 V1 数据：工艺 → 裂纹 + 几何）

> 数据：`D:\SEproject\dataset\online\对激光焊接的钢-铜搭接接头的数据集\Definitive screening steel-copper lap joints V1.xlsx`
>（360 行真实数据、50 条裂纹、仅 **5 道焊缝**——按焊缝分组的 CV 折数受限于此，指标仅供参考趋势）。

用途：同一组工艺参数同时预测“裂纹风险”和 4 个几何量（钢侧/铜侧熔宽、铜侧熔深、间隙）。

```powershell
cd test
.\.venv\Scripts\python.exe train_multiout.py                # 训练（含 5 折按 weld 分组 CV，模型存 models\xgb_multiout）
.\.venv\Scripts\python.exe evaluate_multiout.py             # 打印已存报告；加 --recheck --weld-detail 复核 CV/逐焊缝
.\.venv\Scripts\python.exe predict_quality.py --power 1050 --speed 1 --gas 15 --focal 0 --angular 0 --thickness 0.6 --pos 8
```

网页（先启动主系统）：http://localhost:18080/quality —— 填参数预测裂纹与几何；「让 AI 解释」需要 `QA_ENABLED=True` 且配置好 Key/Ollama。
